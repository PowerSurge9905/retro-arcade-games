## Game Manuals
### --- Breakout ---
Try to break all of the bricks!<br/>
Move your paddle using the left and right arrow keys.<br/>
Keep your ball on the screen, and see how long you can last!<br/>
Use the escape key to pause.<br/>

### --- Star Sweeper ---
Sweep up the stars!<br/>
Move the black hole using the up, down, left, and right arrow keys.<br/>
Sweep up as many stars as you can, but watch out for asteroids and UFOs!<br/>
Use the escape key to pause.<br/>
